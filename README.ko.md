# Q-Dong · 큐동

**개인 프로젝트** — 자연어로 입력한 예산과 라이프스타일을 분석해 서울의 동네를 지도 위에서 추천하는 풀스택 웹 애플리케이션입니다.

- Next.js·React·Leaflet 지도와 Python·FastAPI 백엔드를 연결합니다.
- Snowflake Marketplace의 세 데이터셋을 조인하고 Cortex로 입력 조건을 해석합니다.
- 추천 점수는 선택한 생활 항목의 데이터 순위를 바탕으로 애플리케이션에서 계산합니다.
- SQL 값 바인딩, 입력 검증, API 접근 코드, 요청 크기·속도 제한과 보안 회귀 테스트를 포함합니다.

실행에는 본인 Snowflake 계정과 데이터셋 접근 권한이 필요합니다. 계정 비밀번호나 API 키를 저장소에 넣지 마세요.
